# 시각화 지침

- 작업 버전의 지침·README, [생성 설계 5절](../plan/data_generation_v1_design.md), [공통 형식 지침](../contracts/AGENTS.md)을 먼저 읽는다.
- 이 폴더는 데이터 읽기·재생·비교·표시를 담당한다. 운동모델이나 예측 모델을 별도로 재구현하지 않는다.
- XY·XZ·3D는 하나의 3D 데이터와 공통 시간축의 서로 다른 보기다. 보기마다 새 궤적을 만들거나 좌표·시간을 임의 변경하지 않는다.
- 원본 관측·추정치·시뮬레이션 정답·예측은 명확히 구별한다. 재생을 예측 성능이나 물리 타당성의 증거로 취급하지 않는다.
- 축 이름·방향·단위를 표시하고 과학적 거리 왜곡을 피한다. 비등방 확대나 보간이 있으면 화면에 명시하고 원자료와 구별한다.
- Browser UI 구현 시 관련 시각 디자인·접근성 지침을 읽고 키보드 조작, 초점, 색 외 구분, 화면 크기 대응을 검증한다. 장식보다 데이터 해석을 우선한다.
- 원자료를 덮어쓰지 않는다. 내보낸 이미지·영상·보고서는 `outputs/visualization/<version>/<run_id>/`로 보낸다.
- UI 기술·배치·설정은 승인된 설계 범위 안에서 정한다. 현재 viewer나 재생 테스트가 구현된 것으로 쓰지 않는다.
