비행 시뮬레이션

직접 조종하고, 관측으로 예측하고, 비행 결과와 비교합니다.

기체와 출발 조건을 설정하세요.

운용 조건

평지 · 무풍 · 독립 비행. 관측 오차는 각 축에 적용됩니다.

검증 모델

실행 시작 시 checkpoint를 고정합니다. 관측 이력이 모인 뒤 예측을 표시합니다.

기체 구성

한 대만 있으면 그 기체만 직접 조종합니다. 여러 대에서는 선택한 한 대 이외의 기체가 시나리오를 수행합니다.

기체 형상과 기울기는 간소화된 표현입니다. 실제 기체 안전 한계를 나타내지 않습니다.
