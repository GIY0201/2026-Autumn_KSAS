# 임시 파일 지침

- [README](README.md)를 읽고 해당 작업에서 만든 파일만 다룬다.
- 필요할 때 작업별 하위 폴더를 사용한다. 원본·최종 문서·최종 결과의 유일한 사본을 두지 않는다.
- 완료 후 본인이 만든 임시 파일만 정리한다. 삭제/이동 전 절대 경로와 작업 범위를 확인하며 `temp/` 전체를 일괄 삭제하지 않는다.
- 사용자의 기존 파일, 다른 작업의 임시 파일, 원본 ZIP, 실행 결과를 청소 대상으로 확대하지 않는다.
- 보존할 설계는 `plan/`, 실행 결과는 `outputs/`의 담당 경로로 정리하고 출처를 남긴다.
