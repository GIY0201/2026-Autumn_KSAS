# 데이터 생성 v1 — X8

- [README](README.md), [생성 설계](../../plan/data_generation_v1_design.md), [실행 checklist](../../plan/x8_v1_implementation_checklist.md)를 먼저 읽는다.
- 첫 범위는 X8 실측 기동 재현 → 새 3D 궤적 생성 → 로컬 Browser 평면/3D 재생이다. quadrotor·VTOL·조류는 후속이며 첫 X8 전달에 포함하지 않는다.
- 기본 Episode는 빈 공간·단일 물체·연속 60초, Local ENU(x=East, y=North, z=Up), 5 Hz·301개 시점이다. 생성 표형 데이터는 CSV로 보관한다.
- 2025 X8 nonlinear 모델을 기준으로 설계한다. 2018/2024 계수나 다른 기체의 설정을 섞지 않는다. 표·식·단위·부호와 출처를 확인하기 전 임의 계수로 채우지 않는다.
- 재현에는 원자료의 입력·초기조건·바람·전압·시간 정렬을 사용한다. 신규 생성에는 독립 ambient wind를 넣지 않고 calm trim을 별도로 구한다.
- 원본의 GPS 필드·위경도·지리 좌표는 X8-GEN-V1에서 읽거나 변환하지 않는다. source replay는 운동 관련 입력·속도·자세·각속도·specific force·바람·전압 대조로 한정한다.
- 첫 기동은 정상 직진·속도 변화·좌우 선회·상승·하강과 동시 복합 기동이다. 다양성을 우선하며 기체별 전환 반응과 상태 연속성을 유지한다. 실속·곡예·hover·순간 방향 전환을 지원한다고 주장하지 않는다.
- 근거 없는 유지/전환 시간은 기본값으로 쓰지 않는다. 철회된 5~15초·1~3초·10~20초 제안과 실제 남은 상세는 [결정 대조표](../../plan/decision_reconciliation.md)를 따른다.
- 초기 오차는 매 0.2초 새로 추출하는 축·시간 독립 zero-mean Gaussian이며, `sigma=1, 3, 5 m` 세 관측본을 같은 truth Episode에서 만든다. 특정 센서 재현이나 time drift는 주장하지 않는다.
- 합성 pilot은 물체 종류별 Episode 단위 70/15/15, 학습 구간 무작위·평가 구간 고정이다. 공개 X8 TRAIN/VALIDATION과 섞지 않으며 60초 저장 길이로 RED-SDS 학습 context를 자동 결정하지 않는다.
- X8 TRAIN 점검 수치와 알려진 전처리 주의사항은 설계 3절의 이전 점검 기록이다. 원본/해시를 재확인하지 않은 구현에 검증 완료 표시를 붙이지 않는다.
- X8 VALIDATION 4개는 이전 점검에서 미열람이다. 재현 설정·평가 절차를 먼저 고정하고 별도 평가 단계에서 사용한다. 보고된 예제 오차를 보편적 합격선으로 쓰지 않는다.
- 짧은 실측 기동을 이어서 18초 실측 평가창으로 취급하지 않는다. 긴 신규 합성 궤적의 성능과 실측 일반화를 구분한다.
- 결과는 `outputs/data_generation/v1/<dataset_id>/`에 새 ID로 보관한다. 5 Hz 출력 주기와 0.0025초 RK4 물리 적분 간격은 별개다. 제어·기동 검사 주기는 0.01초다.
