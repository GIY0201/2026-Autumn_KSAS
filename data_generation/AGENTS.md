- 외부 자료 작업은 [원본 지침](../data_sources/AGENTS.md), 입출력 변경은 [공통 형식 지침](../contracts/AGENTS.md), 결과 저장은 [결과 지침](../outputs/AGENTS.md).

## 책임과 경계

- 이 폴더의 운동모델은 새 궤적을 생성하는 물리 모델이다. `models/`의 미래 예측기와 구분한다.
- 실측·논문 근거를 가진 기체별 운동모델과 새 기동 명령으로 연속 궤적을 생성한다. 원본 재생·조각 이어붙이기를 신규 운동모델 생성이라고 부르지 않는다.
- 한 기체의 계수나 관측 범위를 전체 비행기·UAV·조류에 일반화하지 않는다. 실측 범위, 모델 적용 범위, 설계용 제한은 따로 기록한다.
- 원본 재현, 무풍 신규 생성, 관측오차 합성을 분리한다. 바람 생략을 공기역학 생략이나 실측 데이터 무풍 판정으로 해석하지 않는다.
- 생성 정답·관측·기동 명령·설정을 구분하고 공통 형식으로 내보낸다. 정답은 평가용으로만 제공한다.
- 기동 다양성은 먼저 명령·순서·지속시간·초기조건으로 만든다. 근거 없는 독립 계수 난수화나 순간 꺾임·위치 강제 덮어쓰기를 하지 않는다.
- 비행/생성 episode 단위로 분할하고, 같은 원본의 중첩 window나 파생본이 학습·평가 경계를 넘지 않게 계획한다.
- 구현·schema·실행 설정은 별도 승인 전 작성하지 않는다. 각 버전의 수치·성능 검증 상태는 해당 README와 실행 기록에만 적는다.
