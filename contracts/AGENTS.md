# 공통 형식 지침

- 작업 버전의 지침·README, [생성 설계 4절](../plan/data_generation_v1_design.md), [모델 인계](../plan/model_design_handoff.md)를 읽는다.
- 좌표계·단위·시간축·입출력 의미·버전 호환성을 이 폴더에서 정의한다. 각 모듈이 같은 이름의 열을 다르게 해석하게 두지 않는다.
- 원본 관측, EKF/유도 추정치, 시뮬레이션 정답, 예측을 구분한다. 공개 관측 입력과 평가 전용 정답은 별도 인터페이스로 관리한다.
- 불확실성 표현의 종류·단위·좌표·유효성을 함께 다룬다. 한계/표준편차/공분산/확률구간을 같은 숫자로 간주하지 않고 누락을 0 오차로 해석하지 않는다.
- source timestamp, episode 상대시간, 미래 상대시간, 실제 재생시간을 구분한다. 중복/역전 timestamp와 결측 처리 규칙을 명시한다.
- 미지원 형식·버전·차원 조합은 오류로 처리하도록 설계한다. 확인 없이 최신 버전이나 묵시적 좌표 변환을 선택하지 않는다.
- `contracts/`는 공통 형식·검증의 소유자다. 기체 계수, 학습 알고리즘, UI 내부 상태, 실행 결과를 넣지 않는다.
- 공통 형식을 바꾸면 관련 생산자·소비자 지침과 테스트 영향을 함께 확인한다. 기존 결과를 새 형식으로 조용히 덮어쓰지 않는다.
