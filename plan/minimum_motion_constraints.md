# 객체별 최소 운동 제약조건

날짜: 2026-09-07  
상태: **이전 초안 보존 — 기존 설정값을 새 제약의 채택안으로 삼는 방향은 철회.** 코드·설정에는 미반영.

2026-09-07 정정: 사용자가 Gazebo 계수·식에서 계산한 근거를 요청했는데 이 초안은 기존 테스트 설정 유지 중심으로 작성되었다. 따라서 아래 수치표·적용 제안은 현재 채택안이 아니다. 최신 근거와 실제 계산값은 [Gazebo 계수 기반 최소 제약](gazebo_minimum_constraints.md)을 우선한다. 2절의 사용자 시나리오 합의는 보존한다.

## 1. 목적과 범위

목적은 실제 기체나 내부 장치를 정밀 재현하는 것이 아니라, **객체별 특징을 유지하면서 과도한 움직임을 막는 질점 시뮬레이션 제약**을 정하는 것이다.

흐름: 기존 자료·모델·설정 → 속도·가속·선회·수직 운동의 최소 제약 → 단계별 기동 하나 선택 → 연속 궤적 생성.

- 공개 자료와 6-DOF/Gazebo는 수치 선택의 참고 근거다. 별도 참조 모델 이식·실비행 재현·제어기 추종 성공을 생성기의 선행 조건으로 요구하지 않는다.
- 모든 수치를 측정값이라고 주장하지 않는다. 합의값, 기존 설계값, 자료에서 가져온 참고값, 식으로 계산한 값을 구별한다.
- 검사는 제약 준수·연속성·단계 전환·시간 내 완주에 한정한다. 실기체 전체 성능이나 안전 보장이 아니다.
- 기존 60초 생성기, 8088 viewer, source·기존 결과·관측/평가 경계는 이 문서 작성으로 변경되지 않는다. 최대 600초 시나리오와 상태 검토 패널은 별도 구현 단계다.

## 2. 이미 합의한 시나리오 규칙

[질점 전환 명세 5절](point_mass_migration_design.md)의 합의를 보존한다.

| 항목 | 유지할 규칙 | 구분 |
|---|---|---|
| 시나리오 | 지상 고도 0m 출발 → 이륙 → 공중 기동 → 착륙·정지, 전체 최대 600초 | 사용자 합의; 현재 60초 진단과 구별 |
| 고도 | 최대 1,000m. 모든 시나리오가 이 고도까지 올라갈 필요는 없음 | 상한이지 도달 목표가 아님 |
| 고정익 초기 상승 | 100m까지 이륙 방향 직선 상승, 유지 경로각 +3도 | 300m 선회 시작안은 채택하지 않음 |
| 고정익 기동 상승 | 100m 초과에서 선택한 상승 기동 하나, 상승 경로각 최대 +10도 | 고도만 넘었다고 순간 선회하지 않음 |
| 고정익 접근 | 100m 초과에서 하강 경로각 크기 최대 10도. 100m 진입 전에 방향 정렬·각도 전환 완료, 이하 최종 접근 −3도 | 저고도에서 회전하며 접근하지 않음 |
| 단계별 다양성 | 상승·순항·접근마다 기동 종류 하나 선택. 직선도 정식 선택지 | 한 단계에 좌선회→S자→나선을 연속 나열하지 않음 |
| 기동의 구성 | 안정 구간 → 부드러운 진입 → 선택 기동 → 회복 → 안정 구간 | 안정은 반드시 수평 직선이나 무가속을 뜻하지 않음 |

3도는 해당 직선 상승·최종 접근의 **유지 경로각**이다. 지면 이탈, level-off, 착륙 flare·정지에는 연속 진입·회복을 둔다. 경로각은 기체 pitch가 아니다. 고정익의 100m/3도/10도 규칙을 수직 이착륙하는 다른 객체에 일괄 복사하지 않는다.

## 3. 이전 수치표 — 기존 테스트 설정 대조 기록, 채택안 아님

모든 속도는 Local ENU의 **수평 속력** 또는 **수직속도**다. 전체 속력이나 대기속도와 혼동하지 않는다. 대칭 상한은 현재 설정을 보존한 설계이며 실제 상승/하강 또는 가속/감속 성능이 대칭이라는 주장이 아니다.

| 항목 | 고정익 UAV | 쿼드콥터 | VTOL | 헬기 |
|---|---:|---:|---:|---:|
| 수평 속력 (m/s) | 공중 14–22; 지상 정지는 별도 | 0–0.75 | 전체 0–8; 고정익 순항 모드 4–8 | 0–40 |
| 수평 벡터 가속도 상한 (m/s²) | 약 2.628 | 1.0 | 3.0 | 2.5 |
| 접선 가속·감속 상한 (m/s²) | 별도 상한 1.0, 수평 예산도 함께 적용 | 1.0, 수평 예산도 함께 적용 | 별도 추가값 없이 수평 예산 내 | 별도 추가값 없이 수평 예산 내 |
| 수직 가속·감속 상한 (m/s²) | 0.5 | 1.0 | 1.5 | 1.0 |
| 수직속도 크기 (m/s) | 아래 4절의 수평속도·경로각 연동안 | 0.4 | 2.0 | 4.0 |
| track 선회율 절대 상한 (deg/s) | 약 10.754 | 약 57.296 | 45 | 20 |
| 공중 정지/호버 | 허용하지 않음 | 허용 | 회전익·호버 모드만 허용 | 허용 |

선회율의 표 상한을 모든 속도에서 그대로 적용하지 않는다. **5절의 가속 예산과의 교집합**이 실제 허용값이다. 수평·수직 가속 한도는 별도이며, 표에 3차원 전체 가속도 상한 하나를 새로 추가하지 않는다.

## 4. 고정익 경로각과 현재 설정의 충돌 처리안

현재 Stage 1은 `maximum_vertical_speed_mps=1.0`, `maximum_track_path_angle_deg=20.0`, 초기 고도 80–120m인 공중 진단이다. 따라서 이 설정을 그대로 사용하면서 0m 이륙·3도/10도 규칙을 구현했다고 말하면 안 된다.

새 시나리오의 **설계 제안**은 20도 제한을 합의한 단계별 3도/최대 10도로 대체하고, 독립적인 수직속도 1 m/s 제한 대신 다음 관계를 사용하는 것이다. 기존 YAML을 수정한 것은 아니다.

`w = v_h × tan(γ)`

- `v_h`: 수평 속력, `w`: 부호 있는 수직속도, `γ`: 경로각.
- 초기 직선 상승 유지 목표: `γ=+3°`. 최종 직선 접근 유지 목표: `γ=−3°`.
- 100m 초과 상승/하강: `|w| ≤ v_h × tan(10°)`와 수직 가속 상한을 함께 적용.
- 22 m/s에서의 약 3.879 m/s는 계산 예이지 모든 속도에서 가능한 독립 수직속도 상한이 아니다.

| 수평 속력 (m/s) | 3도 유지 시 수직속도 크기 (m/s) | 10도에서의 수직속도 크기 (m/s) |
|---:|---:|---:|
| 14 | 0.734 | 2.469 |
| 18 | 0.943 | 3.174 |
| 22 | 1.153 | 3.879 |

22 m/s에서는 3도만으로도 기존 수직속도 1 m/s 상한을 넘는다. 낮은 속도에서 경로각 10도 한도를 만족하던 상태도 감속하면 위반할 수 있으므로 **목표뿐 아니라 전환 중 실제 속도·수직속도 조합**을 검사한다. 모순되는 요청은 명시적으로 재구성/거부하고 숨겨서 clipping하지 않는다.

고정익 지상 출발·정지에는 속력 0을 허용하는 별도 지상 단계가 필요하다. 공중 최소 속력 14를 지상에 적용하거나, 반대로 공중 단계에서 정지를 허용하지 않는다. 이착륙 연결은 2단계 구현 대상이며 14 m/s를 실측 실속속도 또는 인증된 이륙속도로 부르지 않는다.

## 5. 속도·선회·가감속을 묶는 공통 규칙

수평 속력 `v_h`, track 선회율 `ω`(rad/s), 접선 가속 `a_t`, 수평 가속 예산 `A_h`에 대해:

`a_lateral = v_h × ω`  
`a_t² + (v_h × ω)² ≤ A_h²`

이 식과 표의 별도 접선/선회율 상한을 동시에 적용한다. 속도를 올리면서 선회할 때 두 성분이 같은 수평 가속 예산을 나눠 쓴다.

정속 수평 선회라면 `R = v_h / |ω|`이고, 가속 예산만으로 얻은 최소 반경은 `v_h² / A_h`다. 선회율 상한도 포함하면:

`R_min = max(v_h / ω_cap, v_h² / A_h)`  (정속, `v_h > 0`)

| 계산 예 | 가속 예산 적용 후 최대 선회율 | 정속 최소 반경 |
|---|---:|---:|
| 고정익 18 m/s, `A_h≈2.628` | 약 8.364 deg/s | 약 123.303m |
| VTOL 8 m/s, `A_h=3` | 약 21.486 deg/s, 표의 45보다 작음 | 약 21.333m |
| 헬기 40 m/s, `A_h=2.5` | 약 3.581 deg/s, 표의 20보다 작음 | 640m |

이것은 선택한 질점 제약으로 계산한 값이며 X8 6-DOF의 관측 반경이나 실측 성능값이 아니다. 호버에서는 track 방향·선회 반경이 정의되지 않으므로 0m 반경으로 표시하거나 body yaw 회전으로 해석하지 않는다. 쿼드콥터·헬기의 정지 후 다른 방향 이동도 기체 앞/뒤 자세를 재현했다는 의미는 아니다.

## 6. 객체별로 남길 최소 행동 규칙

| 객체 | 최소 단계·행동 규칙 |
|---|---|
| 고정익 | 지상 가속 → 직선 이륙·초기 상승 → 선택 상승 하나 → 선택 순항 하나 → 선택 접근 하나 → 정렬된 최종 접근·착륙·지상 감속. 공중 호버·수직 이착륙 금지 |
| 쿼드콥터 | 수직 이륙·상승, 호버, 방향을 선택한 수평 이동·가감속, 고도 변경, 수직 착륙. 정지·재출발은 허용하되 속도 벡터를 순간 반전하지 않음 |
| VTOL | 회전익 이륙·호버 → 가속하며 순항 전환 → 고정익 순항·선회 → 감속하며 호버 전환 → 수직 착륙. wing 모드에서 0m/s로 즉시 바꾸지 않음 |
| 헬기 | 수직 이륙, 호버, 수평 이동·선회·가감속, 고도 변경, 수직 착륙. 고정익의 공중 최소속도·저고도 3도 접근을 강제하지 않음 |

VTOL 전환은 간소화 모델의 모드 전환 규칙이면 충분하다. 현재 순항 하한 4 m/s를 사용하는 초안에서는 가속 전환 중 이를 충족한 뒤 wing 모드로 진입하고, 감속은 transition 모드에서 진행해 hover로 끝낸다. 각 모드의 허용 범위와 실제 상태를 함께 확인한다. 자세·조종면·로터 틸트의 전체 재현은 추가하지 않는다.

현재 VTOL의 reference blend 1초와 전환 reference 4–5초, 헬기의 응답시간 등은 이미 있는 **명령 전환 설정**이지 실측 성능 한계가 아니다. 전환시간을 새로운 물리 제약으로 추가하지 않고 가속 한도와 함께 사용한다. `T ≥ |Δv| / a_max`는 단순 직선 속도 변경의 최소 시간 확인식일 뿐 선회·고도 변경이 겹친 전체 기동의 완료시간 보장은 아니다.

## 7. 이번 수준에서 필요한 확인과 남겨둘 일

필요한 확인은 다섯 가지다.

1. 위치·속도가 연속이고 지면 아래로 내려가지 않는가? 착륙 시 마지막 위치나 속도를 강제로 덮어쓰지 않는가?
2. 현재 상태와 전환 중 상태가 속도·가속·각도·선회 예산을 함께 만족하는가?
3. 공중 고정익 정지, wing 모드 VTOL의 즉시 호버, 순간 방향 반전처럼 정한 행동 규칙을 어기지 않는가?
4. 선택한 기동의 진입·유지·회복과 이착륙을 포함해 600초 이내에 끝날 수 있는가?
5. 사용한 값이 합의·자료 참고·설계·계산 중 무엇인지 추적할 수 있는가?

**시간과 최대 고도는 함께 확인한다.** 예를 들어 수평속도 22 m/s, 저고도 100m는 3도, 그 위는 10도로 유지한다고 해도 1,000m 상승 후 복귀에는 이상적인 일정각 구간만 약 637.5초가 필요하다. 지상 구간·연속 전환·순항 시간도 제외한 계산이다. 따라서 1,000m는 상한으로 유지하되 각 시나리오의 목표 고도를 600초 예산에 맞게 고른다. 최대 고도를 낮추는 새 합의나 시간을 늘리는 변경을 조용히 하지 않는다.

X8의 `terminal_target_met`는 설정된 시간 동안 속도·bank·상승률 목표 허용오차를 충족했는지를 나타낸다. 이전 9/14는 **최소 제약 설계의 합격률이 아니다.** 미충족 조건에서도 유효하게 계산된 속도·가속도·곡률은 달성 상태를 명시해 참고할 수 있다. 다만 명령을 달성한 정상상태 성능이나 기체 최대 한계라고 바꾸어 부르지 않는다.

이번 문서는 값과 규칙을 정리한 것이다. 새로운 YAML 적용, 600초 계약 변경, 지상 이착륙·상태 패널 구현, 참조 모델 추가 실행, 서버 재시작, Git commit/push는 하지 않는다. 다음 구현의 핵심 변경은 **고정익의 경로각–수직속도 연동과 단계별 지상/공중 제약 적용**이다.
