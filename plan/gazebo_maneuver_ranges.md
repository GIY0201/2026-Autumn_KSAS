# Gazebo 기반 함수의 기동별 참조 범위

날짜: 2026-09-08. 출처: 사용자 요청 “Gazebo 함수를 활용해서 고정익 항공기의 각 움직임별 제약조건 최소~최대까지 … 헬기도, VTOL도”.

후속: 35 m/s 시험 끝점과 최고 속력을 구분하기 위해 [정상 힘 균형의 속력 상단 탐색 및 미충족 원인](gazebo_speed_boundaries.md)을 추가했다. 아래 368개 동적 시험 결과는 수정하지 않고 이전 기록으로 보존한다.

## 범위와 이번 계산

기존 `gazebo_reference.py`, `gazebo_trials.py`, `gazebo_reference_run.py`를 그대로 사용한다. 고정익 RC Cessna, Standard VTOL 고정익/회전익/전환, 소형 헬기의 명령 격자를 확장한다. 실제 Gazebo/PX4 runtime이나 지상 이착륙 모델을 새로 설치·구현하지 않는다. 기존 UI·질점 profile·원본·이전 결과는 변경하지 않는다.

| 대상 | 시험 속력 | 수직 조건 | 선회 조건 | 시험 수 |
|---|---|---|---|---:|
| RC Cessna 고정익 | 총속력 10, 15, 20, 25, 30, 35 m/s | 경로각 −10, −3, 0, +3, +10° | bank −15, 0, +15° | 90 |
| Standard VTOL 고정익 | 위와 동일 | 위와 동일 | 위와 동일 | 90 |
| Standard VTOL 전환 | 목표 속력 10, 15, 20, 25, 30, 35 m/s | 수평 목표 | 직선 | 6 |
| Standard VTOL 회전익 | 수평속력 0, 5, 10, 15, 20 m/s | 수직속도 −6, −4, −2, 0, +2, +4, +6 m/s | track 선회율 −20, 0, +20°/s, 수평 0에서는 선회 제외 | 91 |
| 소형 헬기 | 위와 동일 | 위와 동일 | 위와 동일 | 91 |
| 합계 | | | | **368** |

이 격자는 계산량을 제한한 1차 탐색 범위다. 격자 끝점까지 달성해도 물리적인 최대값을 찾았다고 주장하지 않는다. 이전 120조건 시험의 ±10°/s 회전익 조건은 이전 결과로 보존하고 이번 실행과 섞어 하나의 동일 조건 시험처럼 집계하지 않는다.

- 40초 시험: 5초 초기 안정화 + 10초 진입 + 15초 유지 + 10초 회복.
- 적분 0.02초, 저장 0.1초, 초기 고도 300 m. 이는 지상 이륙부터 시험했다는 뜻이 아니다.
- 유지 마지막 3초에서 기존 tolerance를 그대로 적용한다. 속력 0.75 m/s, 경로각/bank 1.5°, 회전익 수직속도 0.35 m/s, track 선회율 1.5°/s.
- source 계수, controller gain·상한 및 시험 합격 허용오차는 기존 설정 그대로다. 목표를 통과시키기 위한 사후 변경은 하지 않는다.
- 10초 진입·회복을 둔 전환 시험도 전체 80 m 이륙·전환·착륙 성공을 뜻하지 않는다. `recovery_complete`는 계산 시간이 끝났다는 표시이며 안정된 호버 도달의 판정이 아니다.

## 표를 읽는 방법

1. **시험 명령 범위:** 이번에 입력한 최소·최대. 실제 달성 범위와 다르다.
2. **실제 응답 범위:** 함수로 계산한 속도·수직속도·선회율·반경·가속도. 실패 조건의 응답도 기록하되 채택 후보와 분리한다.
3. **목표 충족 후보:** 수치 계산이 끝나고 유지 구간 tolerance를 충족한 조건. 실제 기체 또는 600초 전체 시나리오의 성능 한계가 아니다.
4. **범위의 결합:** 같은 trial의 속력·상승률·선회율·반경을 함께 사용한다. 서로 다른 trial의 최댓값을 조합하거나 최소~최대 사이의 미시험 구간을 자동 허용하지 않는다.
5. **사용자 조건:** 고정익 50 m까지 +3°, 이후 최대 +10°, 운용 목표 300 m, 하강 100 m 이하 −3°를 따로 적용한다. tolerance로 통과한 실제 경로각이 사용자 최대 10°를 넘을 수 있으므로 두 판정을 혼동하지 않는다. 30 m/s는 아직 기본 후보다.

기본 함수 테스트는 프로젝트 내부의 고유 임시 경로에서 **16 passed**. 네 입력 실행의 조건 수·inventory hash를 확인했으며 총 저장 시점은 **147,568개**다. `results-analysis`의 근거 분리 원칙에 따라 결정론적 조건 하나를 통계적 반복 표본으로 취급하지 않았고, CI·p-value를 만들지 않았다. 표·그림은 계산된 응답과 목표 충족을 구분한다. 기존 60초 생성기·profile·8088 viewer와 원본 결과는 변경하지 않았다.
