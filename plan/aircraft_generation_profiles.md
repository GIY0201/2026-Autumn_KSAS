# 고정익·헬기·VTOL 행동 특성과 생성 기준

작성일: 2026-09-08  
용도: 논문 작성 시 참고할 객체별 행동 특성과 속도·가속도 요약.

아래 수치는 **현재 데이터 생성기에 적용한 설정**이다. 실제 기체의 성능 한계나 실측 최소·최대 속도를 뜻하지 않는다.

## 1. 기체별 행동 특성

| 구분 | 고정익 | 헬기 | VTOL |
|---|---|---|---|
| 이륙 | 지상에서 전진 가속한 뒤 상승 | 수직으로 이륙 | 수직 이륙 후 전진하며 순항 모드로 전환 |
| 상승 | 전진하면서 직선·선회·S자·나선 상승 | 수직·직선·선회·나선 상승 | 전환 이후 직선·선회·S자·나선 상승 |
| 순항·중간 이동 | 직선·선회·S자·원주비행 | 호버링·직선·선회·S자·원주비행·정지 후 재출발 | 고정익 모드에서 직선·선회·S자·원주비행 |
| 공중 정지 | 포함하지 않음 | 호버링과 정지 후 재출발 가능 | 이착륙 측 회전익 구간에서 호버링 |
| 하강 | 전진하면서 직선·선회·S자·나선 하강 | 수직·직선·선회·나선 하강 | 고정익 하강 후 회전익 모드로 전환 |
| 착륙 | 직선 접근 → 착륙 회복 → 접지 후 감속 | 수평 이동 정지 → 호버링 → 수직 착륙 | 직선 감속·모드 전환 → 호버링 → 수직 착륙 |
| 운용 목표 고도 | 300 m | 500 m | 500 m |
| 시나리오 조합 | 64종 | 96종 | 64종 |

이 표는 생성기에 포함한 행동을 정리한 것이다. 표에 없는 행동이 실제 기체에서 불가능하다는 뜻은 아니다. 헬기의 정지 후 재출발은 현재 생성기에서 기존 진행 방향으로 다시 가속한다. VTOL은 전환 중에 선택 상승·선회·S자 기동을 넣지 않는다.

### 1.1 객체별 행동 목록과 개수

한 시나리오에서는 상승·중간 비행·하강의 선택 행동을 하나씩 고른다. VTOL의 공통 수직 이착륙과 전환 과정도 같은 표에 표시한다. ‘공통’은 매 시나리오에 포함되는 과정이며 선택지 수에 더하지 않는다. 상승과 하강은 같은 경로 모양이라도 서로 다른 단계의 행동으로 센다.

| 객체 | 단계 | 행동 목록 | 개수 |
|---|---|---|---:|
| 고정익 | 상승 | 직선 상승, 선회 상승, S자 상승, 나선 상승 | 4 |
| 고정익 | 순항 | 직선 순항, 선회 순항, S자 순항, 원주비행 | 4 |
| 고정익 | 하강 | 직선 하강, 선회 하강, S자 하강, 나선 하강 | 4 |
| 헬기 | 상승 | 수직 상승, 직선 상승, 선회 상승, 나선 상승 | 4 |
| 헬기 | 중간 이동 | 호버링, 직선 이동, 선회 이동, S자 이동, 원주비행, 정지 후 재출발 | 6 |
| 헬기 | 하강 | 수직 하강, 직선 하강, 선회 하강, 나선 하강 | 4 |
| VTOL | 회전익 이륙·공통 | 수직 상승 | 1 (공통) |
| VTOL | 초기 정지·공통 | 호버링 | 1 (공통) |
| VTOL | 순항 전환·공통 | 고도 유지·직선 전방 가속 | 1 (공통) |
| VTOL | 고정익 상승·선택 | 직선 경사 상승, 선회 상승, S자 상승, 나선 상승 | 4 |
| VTOL | 고정익 순항·선택 | 직선 순항, 선회 순항, S자 순항, 원주비행 | 4 |
| VTOL | 고정익 하강·선택 | 직선 경사 하강, 선회 하강, S자 하강, 나선 하강 | 4 |
| VTOL | 호버 전환·공통 | 고도 유지·직선 감속 및 필요한 잔여 감속 | 1 (공통) |
| VTOL | 착륙 전 정지·공통 | 호버링 | 1 (공통) |
| VTOL | 회전익 착륙·공통 | 수직 하강·저속 착륙 | 1 (공통) |

VTOL의 ‘직선 경사 상승·하강’은 전진하면서 고도를 바꾸는 행동이다. ‘수직 상승·하강’은 수평 위치를 유지하며 고도만 바꾸는 행동이다. 위 공통 과정은 단계별로 묶어 센 것이므로 두 호버링을 서로 다른 고유 기동으로 해석하지 않는다.

| 객체 | 단계별 선택 행동 수의 합 | 전체 시나리오 조합 수 |
|---|---:|---:|
| 고정익 | 4 + 4 + 4 = 12개 | 4 × 4 × 4 = 64종 |
| 헬기 | 4 + 6 + 4 = 14개 | 4 × 6 × 4 = 96종 |
| VTOL | 고정익 선택 행동 12개 (위 공통 6단계 별도) | 4 × 4 × 4 = 64종 |
| 합계 | 객체·단계별 선택 항목 38개 | 224종 |

38개는 객체와 단계를 구분해 더한 수다. 서로 겹치는 움직임을 제거한 고유 행동 종류 수나 학습 라벨 수를 뜻하지 않는다. 좌·우 방향과 속도 차이는 같은 행동의 변형으로 두며, 행동 개수를 늘리지 않는다.

### 1.2 모든 시나리오에 붙는 공통 행동

다음 과정은 선택 행동과 별개로 붙는다. 위의 12·14·12개 또는 시나리오 조합 수에 추가로 곱하지 않는다.

| 객체 | 공통 행동 흐름 |
|---|---|
| 고정익 | 지상 가속·이륙 → 초기 직선 상승 → 선택 기동들 → 최종 직선 접근 → 착륙 회복·접지 → 감속·정지 |
| 헬기 | 수직 이륙 → 초기 호버링 → 선택 기동들 → 수평 감속·착륙 전 호버링 → 수직 접근·저속 착륙 → 정지 |
| VTOL | 수직 상승·이륙 → 초기 호버링 → 순항 전환 → 선택 기동들 → 호버 전환·잔여 감속 → 호버링 → 수직 하강·착륙 → 정지 |

공통 행동 흐름은 읽기 쉽게 묶은 설명이며, 내부 코드의 세부 이벤트 수를 센 표는 아니다. 전체 224개 조합의 한글 목록은 [운동 시나리오 통합 명세](aircraft_motion_scenarios.md)에 정리되어 있다.

## 2. 속도 표 읽는 법

- 수평속도는 지면과 나란히 움직이는 속도다. 상승·하강 중 총속력은 수직 성분도 포함한다.
- 속도 범위는 비행 시나리오 하나를 만들 때 목표값 하나를 선택하는 범위다. 매 순간 새로 뽑지 않는다.
- `0 → 목표속도`는 정지 상태에서 서서히 가속한다는 뜻이다.
- 수직속도는 상승이 양수, 하강이 음수다.
- ‘최대 기준’은 상한으로 사용하는 값이다. 진입·회복과 목표 고도에 맞추면서 실제 속도가 더 작아질 수 있다.

## 3. 고정익

수평 목표속도는 Episode마다 **28.5~30 m/s 중 하나**를 선택한다.

| 행동 | 수평속도 기준 | 수직속도 기준 |
|---|---|---|
| 지상 이륙 가속 | 0 → 선택한 목표속도 | 0 |
| 초기 직선 상승: 50 m까지 | 28.5~30 m/s | 유지 기준 약 +1.49~+1.57 m/s, 상승각 3° |
| 직선·선회·S자·나선 상승 | 28.5~30 m/s | 최대 기준 약 +5.03~+5.29 m/s, 상승각 최대 10° |
| 직선·선회·S자·원주 순항 | 28.5~30 m/s | 0 |
| 직선·선회·S자·나선 하강 | 28.5~30 m/s | 하강속력 최대 기준 약 5.03~5.29 m/s, 하강각 최대 10° |
| 최종 직선 접근 | 28.5~30 m/s | 약 −1.57~−1.49 m/s, 하강각 3° |
| 착륙 회복: flare | 선택한 목표속도 유지 | 하강속도 → 0 |
| 접지 후 감속 | 선택한 목표속도 → 0 | 0 |

50 m까지는 직선으로 상승하고, 그 이후 선택 상승 기동으로 목표 고도 300 m에 도달한다. 하강할 때는 100 m 이하에서 직선 접근을 사용하고, 10 m에서 착륙 회복으로 연결한다.

설정에 있는 공중 최소 수평속도 20 m/s는 기본속도 설정을 검사하는 기준이다. 현재 생성기가 20~30 m/s 전체에서 속도를 뽑는다는 뜻이나 실속속도를 확인했다는 뜻은 아니다.

## 4. 헬기

수평 이동 목표속도는 Episode마다 **14.25~15 m/s 중 하나**를 선택한다.

| 행동 | 수평속도 기준 | 수직속도 기준 |
|---|---|---|
| 수직 이륙: 80 m까지 | 0 | 0에서 증가 후 회복, 최대 기준 +3 m/s |
| 호버링 | 0 | 0 |
| 선택 수직 상승 | 0 | 최대 기준 +4 m/s |
| 직선·선회·나선 상승 | 14.25~15 m/s로 연결 | 최대 기준 +4 m/s |
| 직선·선회·S자·원주 이동 | 14.25~15 m/s | 0 |
| 정지 후 재출발 | 선택한 목표속도 → 0 → 같은 목표속도 | 0 |
| 선택 수직 하강 | 0으로 연결 | 하강속력 최대 기준 4 m/s |
| 직선·선회·나선 하강 | 14.25~15 m/s로 연결 | 하강속력 최대 기준 4 m/s |
| 착륙 전 수평 감속 | 현재 속도 → 0 | 0 |
| 수직 착륙 접근 | 0 | 하강속력 최대 기준 2 m/s, 10 m에서 −1 m/s로 연결 |
| 10 m 이하 착륙 | 0 | −1 → 0 m/s |

80 m까지 수직 이륙한 뒤 선택 상승 기동으로 목표 고도 500 m에 도달한다. 착륙할 때는 40 m에서 수평 감속·호버링을 거쳐 수직 착륙으로 이어진다.

호버링에서는 정답 위치가 고정된다. 화면에서 관측 위치가 흔들리는 것은 별도로 추가한 관측오차일 수 있다.

## 5. VTOL

### 5.1 수직 상승·수직 하강

VTOL은 **수직 상승으로 이륙하고, 수직 하강으로 착륙한다.** 두 행동 모두 수평 위치를 유지한 채 고도만 바꾼다. 전진하며 비스듬히 올라가거나 내려가는 고정익 구간의 ‘직선 경사 상승·하강’과 다르다.

| 행동 | 이동 방식 | 고도 구간 | 속도 기준 | 연결 과정 |
|---|---|---|---|---|
| 수직 상승 | 수평 위치를 유지하며 위로 이동 | 지상 0 → 80 m | 수평속도 0, 수직속도 최대 기준 +3 m/s | 정지 → 부드러운 상승 → 80 m에서 호버링 |
| 수직 하강 | 수평 위치를 유지하며 아래로 이동 | 80 → 10 m | 수평속도 0, 하강속력 최대 기준 2 m/s | 호버 전환·잔여 감속으로 수평 이동을 멈춘 뒤 하강. 10 m에서 수직속도 −1 m/s로 연결 |
| 저속 수직 하강·착륙 | 수평 위치를 유지하며 지상으로 접근 | 10 → 0 m | 수평속도 0, 수직속도 −1 → 0 m/s | 하강속도를 줄이며 접지·정지 |

수직 상승·하강은 모든 VTOL 시나리오에 들어가는 **공통 행동**이다. 앞서 센 12개는 고정익 구간의 선택 행동만을 뜻하며 VTOL의 전체 행동 수가 아니다. 공통 이착륙 행동을 명시해도 선택 조합은 4 × 4 × 4 = **64종**으로 유지한다.

### 5.2 전체 비행의 속도 기준

고정익 구간의 수평 목표속도는 Episode마다 **28.5~30 m/s 중 하나**를 선택한다.

| 행동 | 수평속도 기준 | 수직속도 기준 |
|---|---|---|
| 수직 상승·이륙: 80 m까지 | 0 | 최대 기준 +3 m/s, 끝에서 0으로 회복 |
| 초기 호버링 | 0 | 0 |
| 순항 전환: 20초 | 0 → 20 m/s | 0 |
| 고정익 상승 진입 | 20 → 선택한 목표속도 | 상승각 최대 10° 기준으로 연결 |
| 직선·선회·S자·나선 상승 | 목표 28.5~30 m/s | 최대 기준 약 +5.03~+5.29 m/s |
| 직선·선회·S자·원주 순항 | 28.5~30 m/s | 0 |
| 직선·선회·S자·나선 하강 | 28.5~30 m/s | 하강속력 최대 기준 약 5.03~5.29 m/s |
| 호버 전환·잔여 감속 | 현재 속도 → 0 | 0 |
| 착륙 전 호버링 | 0 | 0 |
| 수직 하강: 80→10 m | 0 | 하강속력 최대 기준 2 m/s, 10 m에서 −1 m/s로 연결 |
| 저속 수직 하강·착륙: 10 m 이하 | 0 | −1 → 0 m/s |

80 m에서 순항 모드로 전환한 뒤 목표 고도 500 m까지 상승한다. 착륙 측 호버 전환도 80 m에서 시작한다.

호버 전환은 **10초 뒤 반드시 정지하는 방식이 아니다.** 필요한 잔여 감속시간을 추가하고, 수평 이동을 멈춘 뒤 수직 착륙한다. 고정익의 저고도 3° 접근 규칙을 VTOL에 적용하지 않는다.

## 6. 가속도·선회 제한

가속도 제한은 객체별·행동별로 다르게 정하지 않았다. **세 객체에 공통으로 적용한다.**

| 항목 | 현재 설정 | 의미 |
|---|---|---|
| 접선 가감속 | 크기 2 m/s² 기준 | 수평속력을 높이거나 낮추는 데 필요한 연결시간 계산 |
| 수평 합성 가속도 | 크기 ≤ 2.5 m/s² | 가감속과 선회 가속도를 합친 값 검사 |
| 수직 가속도 | −1~+1 m/s² | 상승·하강 속도 변화 제한 |
| jerk | 벡터 크기 ≤ 2 m/s³ | 가속도가 급격하게 바뀌는 정도 제한 |
| 고정익·VTOL 고정익 선회율 | 크기 ≤ 약 3.44°/s, 0.06 rad/s | 진입·회복에서는 더 작음 |
| 헬기 선회율 | 크기 ≤ 약 6.88°/s, 0.12 rad/s | 진입·회복에서는 더 작음 |

가속도의 최소 크기는 따로 강제하지 않는다. 직선 등속비행에서는 0일 수 있지만, 선회에서는 방향이 바뀌므로 속력이 일정해도 가속도가 생긴다. 2.5 m/s²는 수평 가속도 제한이지 전체 3차원 가속도 크기의 제한이 아니다. 실제 수치 판정에는 설정된 작은 허용오차를 적용한다.

## 7. 공통 생성 규칙과 논문 작성 시 주의점

| 항목 | 현재 기준 |
|---|---|
| 운동 표현 | 3차원 질점 운동학 모델 |
| 시나리오 길이 | 이륙부터 착륙·정지까지 최대 600초 |
| 기동 구성 | 상승·중간 비행·하강에서 각각 하나씩 선택 |
| 초기·종료 고도 | 0 m |
| 최대 고도 | 1,000 m |
| 저장 간격 | 0.2초, 5 Hz |
| 환경 | 단일 객체·무풍 |
| 속도 변화 | 이전 상태에서 부드럽게 가속·감속 |
| 출발점 복귀 | XY 위치 일치를 강제하지 않음 |

현재 방식은 **객체별 기본속도 + 단계별 수직속도 + 객체별 선회율 + 공통 가속도 제한**이다. 기동별 최소·최대 성능을 실측하거나 Gazebo에서 검증한 모델이라고 쓰면 안 된다.

논문에는 ‘객체별 행동 특성을 구분한 질점 모델에 생성용 속도·가속도 제한을 적용했다’고 설명할 수 있다. 224개 조합을 마련한 것과 모든 조합의 생성·학습·평가를 완료한 것은 구분한다. 실제 사용한 데이터 개수와 코드·설정 버전은 실행 기록에서 확인해야 한다.

객체 사이에 비슷한 움직임이 존재하므로 궤적만으로 종류를 항상 식별할 수 있다고 가정하지 않는다. 속도·고도 등 생성 설정의 차이에 모델이 의존했을 가능성과 실제 데이터에 대한 일반화는 별도로 평가해야 한다.

## 8. 상세 설명과 근거

이 문서는 표 중심의 요약본이다. 수식·코드·저장 컬럼은 아래 상세 문서에서 확인한다.

- [운동 시나리오 통합 명세](aircraft_motion_scenarios.md): 전체 시나리오·ID 범례와 7.3~7.6절의 속도 선정·계산·저장 방식.
- [전체 비행 설정](../data_generation/v1/configs/full_flight_settings.yaml): 현재 속도·가속도·선회율 설정.
- [전체 비행 생성 코드](../data_generation/v1/full_flight.py): 단계 연결과 제약 검사.
- [데이터 생성 안내](data_generation_current.md): 관측오차·식별 패턴·학습데이터 분할.

기체의 일반적인 성능을 뒷받침하는 외부 문헌 리뷰는 이 문서의 범위가 아니다. 논문에서 실제 기체의 성능을 주장할 때는 기종·조건에 맞는 외부 근거를 별도로 인용한다.
