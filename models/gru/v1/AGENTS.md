# GRU v1 — 기존 기준 보존

- [기존 기준 문서](../../../동적_공중_객체_미래_점유영역_설계.md), [README](README.md), [최신 모델 인계와 차이](../../../plan/model_design_handoff.md)를 읽는다.
- 이 지침은 이전 루트 AGENTS의 GRU 도메인 규칙을 옮긴 것이다. RED-SDS와의 혼합 설계나 GRU 구현 착수를 승인하지 않는다.
- GRU 기준을 명시적으로 작업할 때만 아래 규칙을 적용한다. 변경은 별도 설계 합의와 이유 기록이 필요하다.

## 보존할 규칙

- 입력: 최근 3초·5 Hz의 관측 위치 16개와 timestamp. 상대좌표로 변환한다. 객체 식별 여부/신뢰도는 선택적인 GRU 보조 정보일 뿐이다.
- 출력: 미래 0.2~15.0초의 75개 위치로 된 대표 경로 하나. 새 관측마다 0.2초 주기로 다시 계산한다.
- 객체 크기를 입력받지 않고 7 m × 7 m × 7 m 정육면체로 근사한다. 시뮬레이션 정답은 평가에만 사용한다.
- 평활화는 속도·가속도 계산 분기에만 적용한다. 위치 16개 → 속도 15개 → 가속도 14개를 유지한다.
- 가속도의 축별 음의 최솟값·양의 최댓값을 쓰고 중앙값이나 절댓값 하나의 대칭 확장으로 바꾸지 않는다.
- 기동 이탈 시간은 `h(τ) = min(τ, 3 s)`이다. 감속으로 진행 속도를 음수로 만들지 않고 별도 반전 없이 자동 후진시키지 않는다.
- 대표 경로 + 관측오차 + 고정 크기로 기본 회랑을, 여기에 기동 이탈 범위를 더해 확장 회랑을 구성한다. 확장 회랑은 기본 회랑을 항상 포함한다.
- 경험적 기동 범위이지 formal Reachability·항공 안전 보장·보정된 확률 영역이 아니다.

## 명시적 재논의 없이 도입 금지

- CVAE/seed 기반 다중 경로, 상위 27개 경로 선택, `3×3×3` 방향 격자, 기동 이탈 예측용 두 번째 GRU.
- 별도 물리 도달집합, GRU의 점유 영역 직접 출력, 기존 `occupancy_v2`의 `O_current`/`O_outer`/constrained zonotope 계약.

평활화·관측오차 분포/크기·layer/hyperparameter·식별 표현·이상치 규칙·정량 합격선·회랑 시간 정렬은 미확정이다. 미확정을 코드 기본값으로 조용히 확정하지 않는다.
