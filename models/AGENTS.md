# 예측 모델 지침

## 먼저 읽기

- [모델 설계 인계](../plan/model_design_handoff.md), [기존 GRU 기준](../동적_공중_객체_미래_점유영역_설계.md), 작업 모델·버전의 지침과 README.
- 입출력 작업에는 [공통 형식 지침](../contracts/AGENTS.md), 학습/평가 산출물에는 [결과 지침](../outputs/AGENTS.md).

## 책임과 경계

- 학습·추론·모델 평가는 `models/<model_name>/<version>/`이 담당한다. 데이터 생성용 기체 운동모델은 `data_generation/` 담당이다.
- 최신 인계는 RED-SDS 미래 분포 방향의 합의이다. 기존 GRU 기준의 통합·전환은 미적용이며, 구현 전에 차이와 적용 범위를 명시적으로 정리한다.
- `models/gru/v1/`이 있다는 이유로 GRU 구현이 승인된 것으로 보지 않는다. RED-SDS를 GRU 후속 버전으로 넣거나 아직 구현하지 않을 모델 폴더를 미리 만들지 않는다.
- 예측 입력은 관측과 공개된 불확실성이다. 시뮬레이션 정답·순간 실제 오차·미래 명령·잠재 상태는 입력, 학습 target, 보조 loss로 쓰지 않는다.
- 최신 RED-SDS 인계에서는 긴 관측 시퀀스 학습과 최근 3초·16개 관측만 사용하는 평가를 구분한다. 이 학습 조건을 보존된 GRU에 자동 적용하지 않는다.
- 모든 모델에서 원본/episode 분할 후 window를 만들며 미래/파생본 누출을 막는다. 합성 pilot의 70/15/15·학습 무작위 구간/평가 고정 구간을 유지하되 학습 context 길이는 해당 모델 설계로 정한다.
- 명시적으로 지정한 checkpoint의 manifest로 모델·입력 축·형식 버전을 식별한다. 최신 checkpoint 자동 선택이나 XY/XYZ 불일치의 조용한 변환은 금지한다. 공통 실행 API/배치는 별도 상세화 대상이다.
- 공개 물체 정보의 known/unknown 정책과 생성 profile 정답을 구분한다. optional profile을 첫 RED-SDS의 입력/encoder로 자동 추가하지 않으며 [결정 대조표](../plan/decision_reconciliation.md)를 확인한다.
- 모델 출력의 의미, 관측 likelihood, 실제 중심 분포를 구별한다. 이미 모델에 반영한 장치 불확실성을 마지막에 다시 일괄 더하지 않는다.
- 시간별 포함률, 전체 경로 포함 여부, 부피, 기동 반응, 처리시간을 별도로 평가한다. 목표 확률량·실제 포함률·안전 보장을 동일시하지 않는다.
- Hyperparameter·표본 수·정량 합격선·실행 명령은 미확정이다. 실제 환경과 테스트가 생긴 뒤 README에 검증된 명령만 기록한다.
